# Demo note: v0.6.0 (26 Oct 2026)

What to show, in order.

1. Run `bash scripts/mode.sh get`. It prints the mode. An agent cannot change it.
2. In Auto, approve a PR with the review account, then run `bash scripts/review_merge.sh <pr>`. It merges and closes the story issue.
3. Open `ROADMAP.md` on the `roadmap` branch. The story shows under Delivered a minute later.
4. Run `bash scripts/adopt.sh <child>` on a child repo. It prints what it created. A second run changes nothing.
5. Open a PR with no `Closes #n`. CI fails and says why.
