# Demo note: v0.13.0 (11 Nov 2026)

1. In a project run `bash scripts/features.sh set lanes off`: it rewrites `.shipquick/features.json` and says to open a PR, because the file is a protected path.
2. Start the Desk (`python3 scripts/desk.py`) and open `http://127.0.0.1:8765/`. Pick a feature group, flip a switch, confirm in the row: a PR opens and the row says "Turning off, merge PR N".
3. In a child run `bash knowledge/shipquick_latest/scripts/adopt.sh . --check` with a 73-character commit subject on the branch: it names the commit. Delete the `.git/hooks` files: it says the hooks are configured but not installed.
4. Open a child PR with a 73-character commit subject: the `commit-subjects` job turns the gate red and names the commit.
