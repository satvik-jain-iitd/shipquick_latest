# Demo note: v0.6.1 (27 Oct 2026)

What to show, in order.

1. A project whose `dev` needs a straight history (GoServe). In Auto mode, run `bash scripts/review_merge.sh <pr>` on an approved PR with no flag: it squashes, and the merge goes through.
2. Run it with `--method rebase`: it rebases. Run it with `--method fast`: it prints the usage line and exits 2, nothing merged.
3. On a project with no such rule, run it with no flag: a merge commit, as in v0.6.0.
