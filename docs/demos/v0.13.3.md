# Demo note: v0.13.3 (12 Nov 2026)

1. In a project that follows rule 24, cut a branch from the kit branch and run `git push` with the hook installed and no `BASE` set: the run prints `base: origin/<kit branch> (...)` and the push is not failed for files outside the push.
2. Edit your `.claude/commands/mode.md`, then run `scripts/adopt.sh .`: it prints `kept      .claude/commands/mode.md (yours; differs from the kit copy)` and leaves the file.
3. Put a markdown file with an unclosed code block in an ignored folder and run `bash scripts/check_local.sh md-blocks`: it passes; the same file tracked or new and not ignored fails.
