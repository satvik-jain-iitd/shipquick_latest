# Demo note: v0.14.2 (13 Nov 2026)

1. In a scratch repo, make a branch that changes `tests/unit/parser.spec.jsx`. Write a PR body whose `## Red` section names that path. Run `python3 scripts/check_tdd.py --body-file <body> --base origin/<base>`: it prints `tdd OK: tests/unit/parser.spec.jsx` and exits 0.
2. Same branch, but the `## Red` section names a test file that is not in the diff. The check exits 1 and names that file.
3. In a scratch repo, write `docs/screens.txt` with one real screen name and a `.github/workflows/ci.yml` that runs `bash scripts/screens.sh --check`. Run `python3 scripts/check_screens_wired.py --screens-file docs/screens.txt --workflows-dir .github/workflows`: it prints `screens wired OK` and exits 0. Delete the check step and run it again: it exits 1 and names the "Wiring CI" section of `docs/SCREENS.md`.
4. The order in the "Wiring CI" example (check before upload) is not measured by that script. `python3 -m pytest -q tests/test_screens_doc.py` runs the example through the check and reads the step order.
