# Demo note: v0.9.0 (9 Nov 2026)

What to show, in order.

1. Run `bash scripts/ui.sh docs android-button --dense`. The agent gets the Compose Button rules.
2. Run `bash scripts/ui.sh docs ios-bottomsheet --dense`. It names SwiftUI only, never a Compose API.
3. Run `python3 scripts/check_ui_coverage.py`. It prints each family's gap from the API lists.
4. Open `docs/research/android-m3-api.md`. It names its source, version, date and sha256.
5. Open `ui/android/templates/` and `ui/ios/templates/`. Five screens each, built from library parts only.
6. Run `bash scripts/adopt.sh <child> --check` on a child with `kit_branch`. It reports each branch,
   and it fails when the kit branch is not protected.
