# Demo note: v0.10.0 (9 Nov 2026)

What to show, in order.

1. Run `python3 scripts/check_ui_coverage.py --strict-api`. It passes with no gap on Android or iOS.
2. Open `docs/research/android-m3-api.md` and `docs/research/ios-swiftui-api.md`. Each names its source,
   version, date and sha256, and every row has a kind and a status.
3. Run `bash scripts/ui.sh docs ios-navigationstack --dense`.
   It says "Do not use: NavigationView. Use NavigationStack."
4. Run `bash scripts/ui.sh docs android-widgets --dense`. It names Glance only, never WidgetKit.
5. Run `bash scripts/adopt.sh <child> --check`. On a child without the gate ruleset it prints
   "gate not required" and fails. `adopt.sh <child>` prints the ruleset command that fixes it.
