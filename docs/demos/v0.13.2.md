# Demo note: v0.13.2 (12 Nov 2026)

1. In a project that follows rule 24, set `kit_branch: <branch>` in the caller and open a PR into a branch that has no `CLAUDE.md`.
2. Before: the `environments` job fails with "no such file: project/CLAUDE.md". After: it reads `CLAUDE.md` from the kit branch and prints `environments OK`.
3. Empty the Dev link on the kit branch: the job fails and names `Dev link`.
