# Demo note: v0.15.0 (20 Nov 2026)

1. Run `python3 scripts/sprint_metrics.py --repo satvik-jain-iitd/shipquick_latest --date 2026-11-19 --utc-offset +05:30`. It prints a table, one row per merged PR, and a totals line.
2. Run `python3 scripts/child_bump.py --release-sha <40 hex>`. It prints one line per child (`bump`, `current` or `unread`) and writes nothing.
3. Make a scratch branch with a changed file and run `bash scripts/check_local.sh tests`. It lists the tests it picked and runs only those.
4. Run `COVERAGE_BASE=<report> COVERAGE_CURRENT=<report> bash scripts/check_local.sh coverage`. A changed file that covers less than on the base fails and is named. With a path unset it fails with the reason and never says skip.
5. Open a feature PR into a `train/<date>` branch. Its checks show `gate-light` green and `test` and the five phone jobs skipped.
