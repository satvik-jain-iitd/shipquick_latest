# Demo note: v0.14.1 (13 Nov 2026)

1. In a kit-branch child, on a code branch with only the gate files staged or committed, open a PR with no code file and no `## Red` section. Run `python3 scripts/check_tdd.py --body-file <body> --base origin/<kit branch>`: it prints `tdd exempt: ...` and exits 0.
2. Rename `scripts/gate_files.txt` in a scratch copy and run the same check: it prints one line, `tdd: cannot read scripts/gate_files.txt; ...`, and exits 1, with no traceback.
