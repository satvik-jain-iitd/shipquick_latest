# Demo note: v0.14.0 (13 Nov 2026)

1. In a project whose caller names a `kit_branch`, switch to a code branch that has only the caller and run `adopt.sh . --check`: it prints one `not adopted: gate file <path> is not on <branch>` line for each gate file, with the `--gate-files` fix.
2. Run `adopt.sh . --gate-files` there: it prints `copied` for each gate file and writes no document. Run `git submodule update --init` and commit: the hooks run and the commit passes.
3. Run `adopt.sh . --check` again: it prints `<branch>: adopted, ... gate files equal to <kit branch>`.
4. In a new worktree with an empty kit folder, try a commit: it stops with one ShipQuick line that says `git submodule update --init`.
5. In a Claude Code session with the kit plugin, ask for `PRE_COMMIT_ALLOW_NO_CONFIG=1 git commit -m x`: the guard blocks it and says why.
