# Demo note: v0.11.0 (10 Nov 2026)

What to show, in order.

1. Start a session with the plugin. The context opens with `ShipQuick mode: <mode>` and the ten rules, then the codebase map.
2. Run `bash scripts/adopt.sh <child>` on a child with no rule block. It writes the block; `python3 scripts/check_rule_copies.py --child <child>/CLAUDE.md` passes.
3. Change one word inside the block and run the check again. It fails and names the file.
4. Open a PR that changes code and names no test in `## Red`. The `tdd` job fails and says why.
5. Run `python3 scripts/check_workflow_security.py`. It lists risky workflow triggers and installs without `--ignore-scripts`.
6. Run `python3 scripts/check_shortcuts.py`. It counts the `shortcut:` and `ponytail:` comments and tags those with no trigger.
7. Run `scripts/release.sh v0.11.0 --dry-run` once the gate is green. It names the sha it would tag.
