# Demo note: v0.5.0 (26 Oct 2026)

What to show, in order.

1. Open a PR. CI runs the secret scan, the dependency review and the hygiene checks. All actions are pinned to a SHA.
2. Run `scripts/check_local.sh` on the Mac. It runs the same checks before a push.
3. Open the `roadmap` branch and read `ROADMAP.md`. It shows Vision, Delivered, Now, Next and Board.
4. Open a new issue. The page shows it about a minute later. This works once the workflow is on `main`, because issue runs start from the default branch.
5. Read rules 20 to 30 in `CLAUDE.md`. The review loop (rule 30) is how PRs #46, #48 and #50 were reviewed.
