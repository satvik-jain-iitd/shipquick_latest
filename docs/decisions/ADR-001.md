# ADR-001: Material Design 3 Adoption

**Status**: Accepted  
**Date**: 2026-10-11  
**Decision**: Adopt Google Material Design 3 (M3) as the design system for all UI components, replacing American Express DLS.

## Context
The original American Express DLS had brand-specific colors (#006FCF, Benton Sans typography, 8px spacing) that needed to be replaced with a generalized, project-agnostic design system.

## Decision
Use Material Design 3 (M3) open-source design system from Google. All design tokens, components, and patterns will follow M3 specifications.

## Consequences
- ✅ Design system is now project-agnostic and reusable
- ✅ Consistent with modern UI standards
- ✅ Easy to find replacement tokens and components
- ⚠️ Requires replacing all Amex-specific color/token references
- ⚠️ Icon library changed from `dls-icons` to Material Symbols
