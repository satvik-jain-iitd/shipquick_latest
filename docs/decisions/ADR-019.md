# ADR-019: A child reads its own change map with the kit's reader

Date: 2026-11-13
Status: Accepted (story #498, epic #485 part 4, PR A)

## Context

ADR-018 gave the kit one map and one reader for its own slow jobs. A child has slow jobs too, and its own paths. The reader
had the kit's file names typed in it, so a child could not use it.

## Decision

1. The reader takes the workflow file and the guarded paths as arguments: `--ci` (repeatable, a job may live in any of the
   files), `--guard` (repeatable) and `--decision-job` (the job whose body decides, `ui-changes` in the kit). With no
   argument the values are the kit's today. The kit's `ci.yml` also passes them, so the kit and a child call it the same way.
2. A child's guarded paths are its own map, its decision workflow job and the pin `knowledge/shipquick_latest`. The pin is
   a gitlink, so it appears in `git diff --name-only` as the exact path; a kit bump turns every area on.
3. The child's map is read from the base branch, so a PR cannot weaken the rule it is judged by. The reader itself runs
   from the submodule at the head pin. A PR that changes the reader changes the pin, and the pin is guarded: that run is a full run.
4. `adopt.sh` writes the caller with a `concurrency` block: one run per PR, a new push cancels the old run (as story #484
   did for `ci.yml`). `adopt.sh --check` says so when it is missing.
5. `adopt.sh` does not write a child's build jobs or its map. They are the child's own. `docs/ADOPTION.md` gives a
   copy-ready snippet (a `changes` job, one `if:` per slow job, a last job running `gate`), and a test runs its commands.
   The sample child walk runs it in a generated child: docs only (off), a path of the area (on), a kit bump (all on), and a
   skipped job of an area that is on (the gate fails).

## Known limits

- The reader of the head pin is trusted. A bump that carries a weaker reader is judged by that reader, but the bump itself
  is a full run. The gate of the kit's own `ci.yml` is unchanged.
- A base reader that does not know the new arguments fails closed (every area on), so a child that bumps to this kit runs everything once.
- The map has no area names typed in the reader. A child's areas are its own.
