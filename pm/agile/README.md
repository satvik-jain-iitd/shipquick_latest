# PM / Agile

Product management and agile process for this project.

Everything lives here. Guides first, templates next, sprint records last.

## Files

| File | What it is |
|---|---|
| `AGILE_GUIDE.md` | The model. Cadence, roles, ceremonies, board. |
| `PRIORITIZATION.md` | How to rank work. Value first. No effort estimates. |
| `REFINEMENT.md` | How to groom a story. T-shirt size. Split rules. |
| `SPRINT_PLANNING.md` | How to plan a 1-week sprint. |
| `PI_PLANNING.md` | How to plan a PI (a D increment). |
| `RETROSPECTIVE.md` | How to run a retro and track actions. |
| `RELEASE_GUIDE.md` | Versioning, release steps, rollback. |
| `templates/` | Ready-to-copy files for each ceremony. |
| `sprints/` | One folder per sprint. Plan, review, retro. |

## Read order

1. `AGILE_GUIDE.md` — understand the model.
2. `PRIORITIZATION.md` and `REFINEMENT.md` — before planning.
3. `SPRINT_PLANNING.md` — at the start of each sprint.
4. `RETROSPECTIVE.md` — at the end of each sprint.
5. `RELEASE_GUIDE.md` — at each release.

## The one rule

Work is ranked by value, not by time. AI writes the code. The real limit is human review.
