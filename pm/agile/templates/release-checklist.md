# Release Checklist — vX.Y.Z

- **Version:** vX.Y.Z
- **Increment:** D<n>
- **Date:** YYYY-MM-DD

## Before tagging
- [ ] All sprint stories merged and Done
- [ ] CI green on `main`
- [ ] Demo note exists at `docs/demos/vX.Y.Z.md`
- [ ] `CHANGELOG.md` updated
- [ ] `docs/PROGRESS.md` updated

## Tag and release
- [ ] Create tag `vX.Y.Z`
- [ ] Publish GitHub Release
- [ ] Paste the changelog section as release notes

## After
- [ ] Announce the release
- [ ] Close the increment milestone
- [ ] Move unfinished work to the next sprint
