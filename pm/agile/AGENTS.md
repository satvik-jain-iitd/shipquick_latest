# shipquick_latest — pm/agile/ Notes

> Folder-specific notes only. Root `CLAUDE.md` standing rules still apply here.

- **This folder holds process, not code.** Guides, templates, and sprint records.
- **No effort estimates.** We do not estimate hours or story points. AI writes the code, so effort is roughly flat. See `PRIORITIZATION.md`.
- **T-shirt size only.** `XS, S, M, L, XL`. Size means change surface and risk, not time.
- **Sprint = GitHub milestone.** PI = a D increment (an epic). Story = one issue = one PR.
- **Keep the templates generic.** Any project that clones this template uses them.
- **When you plan or close a sprint, update `sprints/`.** One folder per sprint.
