# ShipQuick roadmap

_23 of 26 stories done. Written by the ShipQuick roadmap workflow from the issues and pull requests. Do not edit by hand. 14 stories still need plain words._

## Vision

> ShipQuick is a ready-made kit and process that lets a small team build a web or mobile app fast, with AI helpers and people who check each other's work.

## Delivered

<details><summary><b>D6 template ready for clone, with Auto mode</b> · 3 done</summary>

- A story is marked done on the roadmap the moment its change is merged, with no hand work. [#70](https://github.com/satvik-jain-iitd/shipquick_latest/issues/70)
- A child project joins ShipQuick with one command instead of copying files by hand. [#68](https://github.com/satvik-jain-iitd/shipquick_latest/issues/68)
- The owner picks how much the agents do alone: Manual, Semi or Auto. [#67](https://github.com/satvik-jain-iitd/shipquick_latest/issues/67)

</details>

<details><summary><b>v0.5.0 Process v2 \(the checks must-haves, later rules, live roadmap\)</b> · 5 done</summary>

- Several coders add rows to the process trace at the same time, and the row numbers never collide. [#64](https://github.com/satvik-jain-iitd/shipquick_latest/issues/64)
- The owner opens one link per project and sees what is built, what is now and what is next, fresh every 15 minutes, with nothing running on his Mac. [#44](https://github.com/satvik-jain-iitd/shipquick_latest/issues/44)
- Every project that uses ShipQuick gets its own roadmap page from GitHub alone, with no n8n and no other tool to set up. [#49](https://github.com/satvik-jain-iitd/shipquick_latest/issues/49)
- A red check always means a real problem: secrets, risky actions and bad dependencies are caught before merge. [#43](https://github.com/satvik-jain-iitd/shipquick_latest/issues/43)
- The owner and every agent read one set of rules: what the checks must check, how the two sessions work, and what this release brings. [#42](https://github.com/satvik-jain-iitd/shipquick_latest/issues/42)

</details>
